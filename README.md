# 🌄 Parallax Scrolling Website — A simple and responsive parallax scrolling website built using only HTML and CSS. It demonstrates smooth scroll effects using layered backgrounds to create a 3D illusion.
## 🚀 Live Preview: [https://parallaxappy.netlify.app/]

## 🛠 Technologies Used: HTML5, CSS3 
## 🎯 Features: Parallax effect, Responsive layout, No JavaScript, Clean code 
## 📁 Files: index.html, style.css
